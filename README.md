# Java Calculator (Menu-Driven)

A menu-driven calculator built using Java that allows users to perform arithmetic operations based on their choice.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus (Remainder)
- Menu-driven program using switch-case
- Handles division by zero

## Concepts Used
- User Input (Scanner)
- Switch-Case (Decision Making)
- Conditional Statements (if-else)
- Arithmetic Operators

## How it Works
1. User enters two numbers
2. Selects an operation from the menu
3. Program performs the selected operation and displays the result

## How to Run
1. Compile:
   javac Calculator.java
2. Run:
   java Calculator
